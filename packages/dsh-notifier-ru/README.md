# dsh-notifier-ru — русские уведомления DSH

Уведомления о работе агента на русском языке: системный тост Windows, когда агенту
нужен ответ, требуется разрешение на инструмент или задача закончилась (в том числе
с ошибкой), звук и дополнительные каналы — ntfy, Gotify, Bark, webhook. Страница
настроек плагина тоже русская.

Это русская редакция плагина
[`@wingsky-1/dsh-notifier`](https://github.com/wingsky-1/dsh-plugin-hub) (автор
wingsky-1, MIT, версия 0.2.11). Спасибо автору за плагин: вся логика событий,
каналы доставки, тихие часы и системный тост через WinRT — его работа.
Здесь переведены тексты и добавлена русская локаль интерфейса; поведение
менялось точечно: deep-link клика по тосту, нативный helper вместо PowerShell,
вид плашек в окне и правило «одно событие — один тост» (см. ниже).

## Что переведено

- текст тостов и уведомлений: ожидание подтверждения, вопрос к вам, задача
  выполнена, подзадача выполнена, ошибка задачи, конец хода, тестовое уведомление;
- длительность («1 ч 2 мин 5 с»);
- страница настроек: 265 строк интерфейса — события, каналы, звуки, тихие часы,
  диагностика и подсказки;
- сообщения проверки значений, ошибки сохранения настроек, проверка адресов
  webhook, ошибки канала ntfy (тема в шаблоне, приоритет), диагностика звука и
  системного тоста, журнал цепочки обновлений хранилища.

Названий инструментов в тексте больше нет: с 0.2.11 апстрим печатает имя
инструмента как есть (`pwsh`, `read`), поэтому переводить там нечего.

Интерфейс клиента по-прежнему знает три локали (zh, en, ru) и переключается по
языку интерфейса. Тексты же тостов всегда русские: в 0.2.11 апстрим добавил
английский каталог, и наша редакция направляет обе локали хоста на русский —
иначе при английском языке хоста пользователь внезапно получил бы английские
уведомления вместо переведённых.

## Отличия от апстрима

| Что | Апстрим | Здесь |
| --- | --- | --- |
| Имя пакета | `@wingsky-1/dsh-notifier` | `dsh-notifier-ru` |
| Папка данных плагина | `$DSH_HOME/@wingsky-1/dsh-notifier` | `$DSH_HOME/dsh-notifier-ru` |
| Языки интерфейса | zh, en | zh, en, ru |
| Клик по системному тосту | просто закрывает его | открывает окно DSH **и переключает на сессию, из которой пришло уведомление** |
| Вид плашки в окне | светлая карточка с эмодзи 🔔 | поверхность тоста DSH: `--dsw-alias-toast-*`, радиус 16, тень lv3, подпись 14/22, SVG-значок по виду события |
| Клик по плашке в окне | закрывает плашку | закрывает и открывает сессию уведомления |
| Системный тост + окно | два уведомления на одно событие | окно остаётся только ради звука: `playOnly`, тихий кадр |
| Объявленный пир `@deepseek-ai/cordis` | зависит от выпуска: у 0.2.11 — точная `4.1.0` | диапазон `^4.0.4` — точная версия лгала бы о совместимости с другими сборками ядра 4.x |
| Пиры `@deepseek-ai/dsh-*` | точная `0.2.2-rc.1` | `^0.2.2-rc.1` — та же сборка ядра, но без запрета на её следующие prerelease |

Своё имя и своя папка данных выбраны намеренно: рядом с русской редакцией может
стоять апстрим, и настройки не будут перетирать друг друга. Ставить обе версии
одновременно не нужно — уведомления придут дважды; выберите одну.

## Как это собрано

Апстрим публикуется уже собранным (`lib/index.js`, `lib/client.js`), исходников
пакета в поставке нет, поэтому правится сборка, а не исходник. Чтобы обновление
плагина не стирало перевод, дельта живёт в этом каталоге как данные:

```
tools/host-texts.mjs    русский текст хост-половины (тосты, ошибки, настройки)
tools/client-texts.mjs  русский текст клиентской половины вне словаря
tools/ui-ru.json        словарь интерфейса страницы настроек (265 строк)
tools/deep-link.mjs     дельта «клик по тосту → сессия уведомления»
tools/banner.mjs        дельта вида плашек в окне (CSS и разметка плашки)
tools/single-toast.mjs  дельта «одно событие — один тост»
tools/bundle-text.mjs   помощники записи дельт в терминах бандла (CSS/код)
tools/localize.mjs      генератор: апстрим → наш lib/
lib/                    собранный пакет (правится только генератором)
```

Что проверяет генератор перед тем, как писать `lib/`:

- архив апстрима совпал по контрольной сумме `sha512` (`@wingsky-1/dsh-notifier@0.2.11`);
- хеши `index.js`, `client.js`, `toast.ps1`, `THIRD-PARTY-LICENSES` совпали с
  зафиксированными в `tools/localize.mjs`;
- каждый китайский фрагмент из таблиц найден в сборке (иначе — ошибка, а не
  молчаливый пропуск);
- каждый якорь дельт (deep-link, вид плашек, один тост) найден в сборке — иначе
  ошибка с перечнем пропавших фрагментов;
- после перевода в строковых литералах не осталось иероглифов;
- набор ключей русского словаря совпадает с ключами `zh`/`en` апстрима.

Дельты вне текстов живут отдельными модулями, у каждой свой ярлык в сообщении
об ошибке:

- **deep-link «клик по тосту → сессия уведомления»**
  ([tools/deep-link.mjs](tools/deep-link.mjs)): хост кладёт `sessionId` в payload
  тоста, тост ставит `launch="dsh-notify://goto/<id>"`, обработчик протокола
  вызывает роут `/api/dsh-notifier/goto` (хост публикует SSE-кадр
  `goto-session`) и поднимает окно через `dsh://open`, клиентская половина
  переключает UI через `ctx.uiWorkspace.openSession(sessionId)`. Без сессии в
  payload (тестовый тост) клик просто поднимает окно. Апстрим проверяется по хешу
  до дельты, результат — по своему зафиксированному хешу после неё.
- **вид плашек** ([tools/banner.mjs](tools/banner.mjs)): пока плашка рисуется в
  окне (канал browser или деградация на небезопасном контексте), она выглядит как
  родной тост DSH — тёмная поверхность в обеих темах (`--dsw-alias-toast-bg`,
  `--dsw-alias-toast-label`), радиус 16, тень lv3, подпись 14/22, глиф слева
  вместо эмодзи (галочка — сделано, восклицательный знак — нужен ответ или
  ошибка, колокол — прочие события). Клик по плашке закрывает её и открывает
  сессию уведомления, `title` плашки — «Перейти в сессию».
- **один тост на событие** ([tools/single-toast.mjs](tools/single-toast.mjs)):
  когда системный канал Windows действительно умеет показать тост, браузерная
  половина остаётся только ради звука (`playOnly`, кадр с `sound: silent`) —
  иначе на одно событие приходят два уведомления. На другой платформе или без
  helper'а плашка в окне остаётся как была.

Показ тоста и обработку клика выполняет нативный
[lib/server/dsh-notify-helper.exe](lib/server/dsh-notify-helper.exe) (исходник —
[tools/helper/NotifyHelper.cs](tools/helper/NotifyHelper.cs), сборка —
`tools/helper/build.ps1`, csc.exe из .NET Framework 4.x): GUI-subsystem, окна
нет никогда, старт мгновенный, PowerShell не нужен — важно для корпоративных
политик AppLocker/WDAC. Helper сам регистрирует в HKCU и AUMID
`DSH.dsh-notifier`, и протокол `dsh-notify://` на себя. Если exe нет (старая
установка), `buildSystemCommand` молча откатывается на апстримный PowerShell
путь: `toast.ps1` + [lib/server/goto.ps1](lib/server/goto.ps1). Пересборка exe
требует обновить `HELPER_SHA256` в `tools/localize.mjs` — `--check` следит.

Собрать заново:

```sh
node tools/localize.mjs                                  # скачает апстрим с npm
node tools/localize.mjs --upstream <каталог или .tgz>     # из своей копии
node tools/localize.mjs --check                           # проверить текущий lib/
```

### Когда выходит новая версия апстрима

1. Обновить `UPSTREAM.version`, `UPSTREAM.integrity` и хеши в `UPSTREAM_SHA256`
   (`tools/localize.mjs`) на новую версию.
2. Запустить генератор: он перечислит фрагменты, которых в новой сборке уже нет, —
   это места, где текст поменялся.
3. Обновить таблицы, дописать новые ключи в `tools/ui-ru.json` и снова запустить
   генератор до чистого прохода.

Апстрим-тексты в наших таблицах сверяются по подписи, а не по версии, поэтому
`--check` покажет расхождения сразу после обновления.

## Состав lib/

| Файл | Что это |
| --- | --- |
| `lib/index.js` | хост-половина: события, каналы, системный тост, хранение истории |
| `lib/client.js` | клиентская половина: страница настроек, словари zh/en/ru |
| `lib/server/channels/impl/system/toast.ps1` | PowerShell-скрипт тоста Windows (апстрим + дельта deep-link) — fallback, когда нет exe |
| `lib/server/goto.ps1` | helper протокола `dsh-notify://` (наш файл, источник — [tools/goto.ps1](tools/goto.ps1)) — fallback |
| `lib/server/dsh-notify-helper.exe` | нативный helper: показ тоста и обработка клика без PowerShell (источник — [tools/helper](tools/helper)) |
| `lib/THIRD-PARTY-LICENSES` | лицензии сторонних библиотек внутри сборки (копия апстрима) |
