# Архитектура

Продукт — это официальный клиент DeepSeek Harness (форк) с офлайн-каталогом для 1С. Приложение и
рантайм живут в репозитории форка; этот репозиторий описывает **состав** и поставляет каталог.

## Слои

| слой | где живёт | роль |
| --- | --- | --- |
| клиент | форк `deepseek-harness`, `apps/desktop` | Electron-хост, Web UI, менеджер обновлений, перенос данных |
| рантайм | внутри клиента (`@deepseek-ai/dsh`) | агент, сессии, инструменты; Node.js ставить не нужно |
| каталог | `installer-flavor.yml` → `apps/desktop/installer-catalog/` | плагины, навыки, правила и MCP-серверы, которые приложение получает без интернета |
| профиль | `%USERPROFILE%\.dsh` | сессии, настройки, ключи, установленные плагины |

## Путь данных при первом запуске

1. Установщик распаковывает приложение и встроенный каталог.
2. Клиент при старте переносит данные предшественника `%APPDATA%\dsh-desktop\harness` в `~/.dsh`:
   сессии и вложения копируются, ключи и реестр рабочих папок сверяются отдельно.
3. Каталог стейджится в профиль `profiles/desktop` и ставится офлайн; отметка о применении —
   `.1c-catalog-applied`.
4. Дальше клиент работает только со своим домом `~/.dsh`; старый профиль не трогается.

## Поставка каталога

`installer-flavor.yml` — источник правды: для каждой позиции указан источник (git-репозиторий с
пином, tgz или локальный пакет) и тип (plugin, skill, rules, payload, mcp). Сборка превращает его в
`installer-catalog/manifest.json` с зафиксированными версиями и digest. Локальная позиция здесь
одна — `packages/dsh-notifier-ru`.

## Обновления

Приложение читает фид `dsh1c.yml` из последнего релиза; клиенты предыдущей линии (`0.11.x`) читают
`latest.yml` — в каждом релизе он остаётся мостом, объявляющим версию выше `0.11.0-2`. Подробности и
правила публикации — `docs/release-runbook.md`.

## Ограничения

- Продукт не содержит второго фронтенда и второго рантайма: всё, что нужно агенту, приходит из
  официального клиента.
- Каталог ставится офлайн и не требует сети при первом запуске.
- Пользовательские данные не покидают машину; телеметрия — только при явном согласии.
