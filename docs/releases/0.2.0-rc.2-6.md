# 0.2.0-rc.2-6

Исправления проблем миграции, выявленных на обновлениях с предыдущей сборки.

- Список сессий больше не пропадает целиком из-за одного файла, который лежит не в своей папке: такой файл пропускается, остальные сессии показываются.
- Настройки менеджера MCP переносятся из предыдущей установки. Серверы, которые уже есть в новом профиле, сохраняются, недостающие добавляются.
- Список моделей и подключённые провайдеры переносятся в новый профиль.

Файлы, которые миграция изменяет, сохраняются рядом с копией `*.before-legacy-migration`. Сессии, вложения и настройки предыдущей установки не изменяются и не удаляются.
