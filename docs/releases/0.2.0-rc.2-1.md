# DSH для 1С 0.2.0-rc.2-1

Сборка переехала на официальный клиент DeepSeek Harness. Для вас меняется немногое:
интерфейс, инструменты 1С и данные остаются на месте — профиль, сессии, настройки,
вложения и установленные плагины переносятся при первом запуске.

## Что изменилось

**Перенос данных.** При первом запуске профиль, сессии, настройки, вложения и
пользовательские плагины из `%APPDATA%\dsh-desktop\harness` копируются в
`%USERPROFILE%\.dsh`. Перенос одноразовый, по маркеру и без перезаписи; старый
каталог не изменяется и не удаляется.

**Первый экран.** Главная кнопка — «Настроить позже»: рабочее пространство
открывается без входа и без ключа. Вход в аккаунт DeepSeek и ввод ключа API
остаются на этом же экране, настройка моделей — в «Настройки → Модели».

**Установщик.** Русские подписи больше не обрезаются: ширина кнопок и подписей
измеряется по тексту, кнопки центрируются. Установщик называется
`DSH-1C-Setup-0.2.0-rc.2-1-win-x64-unsigned.exe`.

**Настройки.** Боковая колонка расширена до 248 px: «1С: Параметры проектов» и
«Центр уведомлений» видны целиком.

**MCP.** Процесс харнесса получает `DSH_HOME`: engram больше не пишет свою строку
в каталог предыдущей сборки, сервер виден в панели MCP-менеджера вместе с `v8std`.

**Обновления.** Сборка проверяет обновления по своему каналу, а для установленных
ранее `0.11.0-2` в каждом релизе остаётся мост: они видят обновление и переезжают
автоматически.

**Состав каталога.** 12 плагинов. Убран `dsh-univer-office`: просмотр docx / pptx /
xlsx и конвертация Office→PDF встроены в клиент, правка файлов — через навыки
`office-*`. Обновлены dshmarket 1.66.37, modsearch 5.10.7, dsh-better-sidebar 0.26.1,
dsh-russian-lang 0.3.48. skill-explorer 0.4.7 и dsh-better-sidebar 0.28 не взяты:
они требуют ядро 0.2.1.

## Установка и обновление

Ставится поверх предыдущей версии; данные переносятся при первом запуске.
Дальнейшие подрелизы приходят автообновлением.

## Состав

- ядро `@deepseek-ai/dsh@0.2.0-rc.2`;
- 12 плагинов, MCP-сервер `v8std`, набор правил 1С `1c-rules 2026.10.14-96c4d96`;
- русский интерфейс и русский установщик.

## Проверено

- чистая установка: каталог ставится сам, 12/12 плагинов, 367 файлов правил,
  14 бандлов профиля;
- перенос данных на копии реального профиля: 145 каталогов сессий, 148 файлов,
  пять рабочих папок — без потерь;
- MCP-строки после первого запуска: `v8std`, `engram`, `rlm`.

## Ограничения

- Установщик не подписан сертификатом: SmartScreen покажет предупреждение
  («Подробнее» → «Выполнить в любом случае»).
