# DSH для 1С 0.2.0-rc.2-3

Исправлен переход с предыдущей версии — замечания после установки `0.2.0-rc.2-2`.

- **Окно первичной настройки больше не появляется у тех, кто уже всё настроил.** Ключ API и
  учётные данные переносятся из предыдущей версии; если ключ вводили там, повторно вводить не нужно.
- **Сессии снова сгруппированы по рабочим папкам**, а не свалены в «Без папки»: список папок и
  принадлежность сессий переносятся и объединяются с тем, что уже есть.
- Починка выполняется сама при запуске — в том числе для тех, кто уже поставил `0.2.0-rc.2-2`.

Ничего не удаляется: прежние файлы настроек остаются на месте, рядом с изменёнными хранится
резервная копия.
