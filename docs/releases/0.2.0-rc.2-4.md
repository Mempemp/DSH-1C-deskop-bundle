# DSH для 1С 0.2.0-rc.2-4

Исправлена установка обновлений.

- Приложение больше не отказывается обновляться, если остановка задач заняла больше выделенного
  времени: подтверждённая остановка задач считается достаточной, а несовпадение по секундам больше
  не блокирует установку.
- Окно ожидания остановки задач увеличено, чтобы тяжёлый профиль с плагинами и MCP-серверами
  успевал завершиться штатно.

Остальное — как в `0.2.0-rc.2-3`: ключ API и учётные данные переносятся из предыдущей версии,
сессии сгруппированы по рабочим папкам.

**Если обновление не встаёт.** Сборки `0.2.0-rc.2-2` и раньше содержат прежнее правило и могут
отказаться устанавливать обновление с сообщением «Не удалось безопасно остановить задачи». В этом
случае один раз поставьте установщик вручную — дальше обновления приходят как обычно.
