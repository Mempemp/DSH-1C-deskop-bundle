# 0.2.2-rc.3-1

Выпуск переводит сборку на ядро DeepSeek Harness 0.2.2-rc.3 и обновляет весь состав —
боковую панель, агентов, справку платформы, проверки кода и плагин параметров проекта.

## Работа с изменениями

В боковой панели есть обзор изменений по веткам, коммитам и типам файлов. Разбор правок
GitHub открывается там же, отмеченное просмотренным синхронизируется с GitHub. Редко
используемые входы панели собраны в «ещё», файл ищется по имени и пути, список плагинов и
список сессий прокручиваются целиком.

## Агенты

Участники команды именуются, работают на нескольких уровнях, а состав участников и панель
задач привязаны к сессии. Совместная работа агентов включена: агент раскладывает задачу по
участникам и ведёт общий список работ. Переключатель режима — в меню модели и режима
рассуждений у поля ввода, выбор запоминается за сессией.

Ответ модели можно продолжить кнопкой «Продолжить» после обрыва, число повторов при сбое
запроса настраивается. Терминал агента живёт в боковой панели, ввод перехватывается
пользователем. Картинки и файлы вставляются в поле ввода, даже когда оно не в фокусе.

## Параметры проекта и проверки кода

Кнопка «Сохранить» в окне «Параметры проекта» пишет поля подключения — путь к базе,
пользователь, пароль, путь к платформе, код доступа, каталог выгрузки. Включённый анализ
кода, набор правил и флаг индекса остаются в файле проекта с прежним значением: статический
анализ работает и после переоткрытия окна. Сохранение подтверждается плашкой «Готово».

Проверки кода идут по профилю правил проекта: включённое правило приходит и при проверке
файла, и при проверке фрагмента, находки уровней `info` и `hint` доходят до агента наравне
с `error` и `warning`. Пятнадцать правил, которые анализатор держит выключенными по
умолчанию, включаются профилем проекта.

## Панель MCP-серверов

Серверы сборки — справка платформы, проверки кода и ответы ИТС — регистрируются в менеджере
MCP и видны в панели со статусом, логом и перезапуском. Поле «MCP-сервер» в параметрах
проекта называет причину отказа словами: занятое имя, недоступный сервер, ошибка запуска.

## Индекс кода

Карточка индекса считает возраст по более свежей из двух отметок — время сборки внутри
индекса и время последней успешной сверки. Индекс, который сверялся недавно, показывается
актуальным и подписан датой сверки; устаревший честно говорит, что устарел по возрасту.
Рядом с «Обновить» стоит «Пересобрать» — полная сборка с нуля обходом папок, для случаев
когда изменения файлов прошли мимо git.

## Справка по платформе

Индекс справки собирается из базы платформы при первом запуске — от секунд до десятков
секунд, до готовности карточка показывает, что индекс загружается. Четырнадцать
инструментов отвечают по синтакс-помощнику, стандартам и методичкам; в ответах есть пометка
`unavailable_in_context` о том, чего в текущей выгрузке нет, и оценка уверенности.

## Проверки кода: движок

Сервер анализа поднимается вместе с приложением и восстанавливается сам после падения:
паузы 3, 8 и 20 секунд, три попытки. Причина падения видна в карточке сервера и в его логе.
Индекс, построенный прошлой версией, читается без перестроек.

## Установка

Установщик ставится поверх прошлой версии. Проекты открываются со своими параметрами,
развёрнутые правила, принятые замечания, индекс кода и сессии остаются на месте, каталог
плагинов обновляется из установщика.
