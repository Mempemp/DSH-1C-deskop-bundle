# DSH для 1С 0.2.1-rc.2-2

Ядро `@deepseek-ai/dsh` 0.2.1-rc.2. Сборка закрывает дефекты, найденные на второй машине
при установке 0.2.1-rc.2-1.

## Индекс кода: включается в параметрах проекта

`dsh-1c-project-properties` 0.8.3 добавляет карточку «Индекс rlm» в окно проекта (после блока
«Правила 1С в проекте»): статус — индекса нет, актуален, устарел по времени/содержимому/структуре,
`rlm-bsl-index` не найден; кнопка сборки или обновления и «Обновить статус». Карточка пишет флаг
`rlmIndex` через маршрут `/project-index` в `.dsh/1c-project.json` — остальные ключи файла не
трогаются, файл общий с RLM-плагином.

Строит индекс `dsh-rlm-tools-bsl` 0.1.10: прогон при старте (`index.autoOnStart`), раз в неделю
(`index.weekly`), одна задача на проект, таймаут 60 минут, лог `logs/index.log` с ротацией.
CLI ищется в `where rlm-bsl-index`, затем `~/.local/bin`, затем `$DSH_HOME`; если не найден,
карточка так и говорит вместо тихого бездействия.

## Комплектный git больше не теряется молча

Две дырки, из-за которых на второй машине не появился `%USERPROFILE%\.dsh\git`:

- сборка каталога печатала `CATALOG COMPLETE` и завершалась с кодом 0, даже пропустив источник
  по ошибке (например `EPERM` на `tools/git` от антивируса). Теперь пропуск даёт
  `CATALOG INCOMPLETE` и ненулевой код, сборка падает;
- раскатка каталога обрывалась на первой же ошибке в дереве содержимого, оставляя дом без
  правил, git и MCP-строки. Теперь каждый элемент ставится отдельно, сбой называет себя в
  `logs/catalog-seed.log`, маркер не пишется и попытка повторяется при следующем запуске;
  копирование делается с тремя повторами на транзиентный `EPERM`/`EBUSY`.

## `dsh-browser-agent` запускается

В исходном архиве плагина `package.json` лежал с BOM, а хост читает манифест через `JSON.parse`:
`Unexpected token '\ufeff'`. BOM снимается при упаковке каталога, то есть защищает любой плагин,
а не только этот.

Браузер в ядре есть только как экспериментальная обёртка над Playwright MCP
(`dsh-experimental-browser-use-playwright-mcp`), в поставку она не входит и требует внешний
`@playwright/mcp` с браузером. Плагин самодостаточен (свой CDP-клиент), поэтому оставлен.

## Состав каталога

16 позиций: 13 плагинов, MCP-строка `v8std`, правила 1С (`1c-rules`, 2026.10.21-18e3383d) и
MinGit 2.56.0.3.

## Установка

Закрыть DSH Desktop перед запуском установщика: при живом процессе мастер открывается и сразу
выходит. Приложение поднимает несколько процессов — закрывать все.
