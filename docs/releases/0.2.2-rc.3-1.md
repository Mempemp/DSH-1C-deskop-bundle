# 0.2.2-rc.3-1

## Ядро

База — DeepSeek Harness 0.2.2-rc.3 (13.11.2026), перенос слоя коммитом `e8c3806f6b` в ветке
`1c/port-0.2.2-rc.3`. От 0.2.2-rc.1 пришли:

- обзор изменений по веткам, коммитам и типам файлов, разбор правок GitHub и синхронизация
  отмеченного просмотренным прямо в приложении;
- именованные и многоуровневые субагенты: состав участников и панель задач на сессию;
- переключение канала обновлений (стабильный, ночной) в настройках приложения;
- редко используемые входы боковой панели уезжают в «ещё», поиск файлов по имени и пути,
  общая прокрутка для списка плагинов и списка сессий;
- подгрузка ранних сообщений при прокрутке вверх, вставка картинок и файлов в поле,
  которое не в фокусе;
- настройка повторов при сбое запроса к модели, кнопка «Продолжить» после оборванного
  ответа;
- терминал агента в боковой панели с перехватом ввода пользователем;
- прогресс загрузки обновления в процентах, состояние проверки обновлений по нажатию;
- плагин импорта истории из DeepSeek App и веб-версии (экспериментальный).

Отказ одного необязательного плагина не мешает загрузке страницы: сообщение с причиной
показывается отдельно, обязательный плагин по-прежнему останавливает запуск.

## MCP-менеджер

Сервис `ctx.mcpManager` в ядре rc.3 принимает сервер через `register(name, entry)`, снимает
возвращаемым disposer'ом, состояние отдаёт в `list()`, перезапуск — в `restart()`. Плагин
параметров проекта выбирает форму по факту наличия метода, поэтому три его сервера
(`1c-platform-context`, `1c-bsl-checks`, `1c-naparnik`) регистрируются и на новой линии, и на
прежней. Поле «MCP-сервер» показывает причину отказа словами; текст исключения туда больше
не попадает.

Наш пакет `@wingsky-1/dsh-mcp-manager` 0.2.14 занимает службу `mcpManager` только если имя
свободно. На rc.3 ядро монтирует собственный менеджер в композиции `web-app` и объявляет это
имя само: повторное `provide` роняло `apply` целиком, ни один маршрут `/api/dsh-mcp/*` не
регистрировался, и панель отвечала `Load failed: HTTP 404`. При занятом имени пакет
дописывает недостающие методы на службу ядра и снимает их при выгрузке. Пакетный прогон —
19 тестов, в том числе `test/dsh-mcp-manager-service.test.ts`.

## Команда агентов

Набор переехал из экспериментальных пакетов в штатные: `agent-team` и `tool-agent-team`
монтирует `dsh-base`, панель — `dsh-web-app`. Экспериментальный профильный бандл, которым
сборка включала режим прежде, выведен из обращения и вычищается загрузчиком. Режим стал
посессионным и по умолчанию выключен.

Сборка возвращает прежнее поведение строкой в профильном слое патчей (`cordis.patch.yml`):
`agent-team` с `defaultEnabled: true` и `maxTasks: 256`. Строка идемпотентна и не трогает
чужие записи слоя; регресс — `apps/desktop/tests/catalog-seed.spec.ts`. Включить или
выключить режим для конкретной сессии можно тумблером «Включить совместную работу агентов»
в меню модели и режима рассуждений у поля ввода; выбор сохраняется в журнале сессии.

Мёртвая строка `ENABLED_BUNDLES` с несуществующим бандлом убрана из `catalog-seed.ts`: она
добавляла нерабочее имя в список профиля и ничего не включала.

## Индекс кода

Карточка индекса считает возраст по более свежей из двух меток — `built_at` внутри индекса и
время последней успешной сверки, которое ведёт плагин. Индекс с несдвинутой меткой сборки, но
свежей сверкой показывается актуальным и получает пояснение с датой сверки; честная старость
(сверка тоже старше `RLM_INDEX_MAX_AGE_DAYS`) остаётся «устарел по возрасту».

Командная строка индексации ищется в порядке: `bin` плагина, `~/.local/bin`, затем `PATH`.
Сборка CLI старше 1.46 при `index update` не сдвигает метку сборки — её появление впереди
нашего окружения давало бесконечное «устарел по возрасту» при формально успешном обновлении.

В карточке рядом с основной кнопкой стоит «Пересобрать» — полная сборка с нуля обходом папок.
Основная кнопка меняет подпись по состоянию: «Собрать» без индекса, «Пересобрать» при
расхождении состава, «Обновить» в остальных случаях.

Регрессы плагина: `test/rlm-index-age.smoke.mjs` (метка сборки отодвинута на 9 суток, сверка
свежая — карточка отдаёт `fresh`), `test/rlm-index-card.smoke.mjs`.
