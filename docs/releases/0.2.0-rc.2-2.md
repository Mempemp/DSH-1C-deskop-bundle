# DSH для 1С 0.2.0-rc.2-2

Тот же выпуск, что `0.2.0-rc.2-1`, с исправленной доставкой обновлений.

- Установленные ранее сборки `0.11.0-2` видят обновление и переходят на новую версию
  автоматически — когда сами проверяют обновления. Опрашивать никого не нужно.
- Новая линия обновляется по собственному каналу, поэтому версии `0.11` и `0.2`
  больше не конкурируют в одном файле обновлений.
- Ставится поверх предыдущей версии; данные — профиль, сессии, настройки, вложения
  и ваши плагины — переносятся при первом запуске.

Состав каталога и проверки те же, что у `0.2.0-rc.2-1`.

SHA-256  (заполняется после сборки)
