# DSH для 1С 0.2.0-rc.2-5

- **Установщик при обновлении больше не спрашивает папку.** Если приложение уже установлено, оно
  ставится на прежнее место, а кнопка называется «Обновить».
- **Приложение запускается с первого клика после выхода.** Закрытие ускорилось: ярлык больше не
  попадает в момент, когда предыдущий процесс ещё завершается.

## Контрольные суммы

```
SHA-256  (заполняется после сборки)
```
