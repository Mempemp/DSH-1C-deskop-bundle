# DSH для 1С 0.2.0-rc.2-7

Браузерные инструменты для агента, уведомления с переходом в сессию и каталог, который больше не
теряет позиции.

## Браузер для агента

- В каталог добавлен `dsh-browser-agent` 1.0.1: 19 инструментов `browser_*` поверх встроенного
  бокового браузера — чтение accessibility-дерева со стабильными `ref`, клики и ввод через CDP,
  история, вкладки, наблюдение за сетью, эмуляция устройства, cookie-vault, несколько независимых
  экземпляров и произвольный вызов CDP.
- `browser_screenshot` в этой версии отключён: на Electron 44 `capturePage()` по `<webview>` роняет
  процесс рендера. Инструмент остаётся в списке, но возвращает пояснение вместо снимка — рабочих
  инструментов 18 из 19.
- Плагин ставится из git по пину коммита (`a69f2ca`), в npm его нет. Его `package.json` записан с
  UTF-8 BOM, поэтому установка требует pnpm 11.7 и новее.

## Уведомления

- Клик по системному тосту открывает сессию, из которой пришло уведомление: `sessionId` проходит из
  интерфейса в payload тоста, ссылка `dsh-notify://goto/<id>` попадает в `/api/dsh-notifier/goto`,
  оттуда кадром `goto-session` — в открытие сессии.
- Тост и обработку клика выполняет нативный `dsh-notify-helper.exe` (.NET Framework, GUI-подсистема)
  вместо `powershell.exe`: без вспышки окна консоли, запуск мгновенный, политики AppLocker и WDAC на
  PowerShell не мешают. Если помощника нет, используется прежняя пара `toast.ps1` + `goto.ps1`.
- При показе тоста помощник регистрирует схему `dsh-notify://` в HKCU на себя.

## Полнота каталога

- Источники больше не выпадают из поставки: манифест с UTF-8 BOM и zip-архив с именами файлов не в
  ASCII раньше приводили к пропуску позиции, и каталог собирался неполным.
- Версия каталога в `manifest.json` соответствует релизу — раньше она оставалась `0.2.0-rc.2-1`
  независимо от номера сборки.

## Ограничения, о которых стоит знать

- `dsh-browser-agent` даёт агенту управление боковым браузером, включая вкладки с вашими логинами.
  Локальный мост плагина слушает `127.0.0.1:8791` с разрешающим CORS (`*`) и постоянным токеном из
  открытого исходника: пока DSH запущен, страница, открытая в любом браузере, может обратиться к
  этому порту. Плагин поставляется как есть, из апстрима, и включён по умолчанию; если такое
  поведение нежелательно, отключите его в настройках плагинов.
- Cookie-vault плагина сохраняет cookie (включая httpOnly) в открытый JSON в
  `~/.dsh/dsh-browser-agent/vault/`.
