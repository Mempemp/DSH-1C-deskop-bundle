# Что лежит внутри сборки

Источники и пины — `installer-flavor.yml`. При сборке из него собирается
`apps/desktop/installer-catalog/manifest.json` с зафиксированными версиями и digest.

## Каталог

17 позиций: 11 плагинов, 3 рантайма, payload правил, MCP-сервер, движок поиска по коду.

### Плагины

| Плагин | Что делает |
| --- | --- |
| `dsh-1c-project-properties` | параметры проекта 1С, правила, анализ кода, 1С:Напарник, MCP `rlm-tools-bsl` |
| `dsh-bsl-editor` | редактор BSL: дерево метаданных, подсветка, диффы, коммиты |
| `dsh-engram-memory` | память агента и MCP-сервер `engram` |
| `dsh-notifier-ru` | русские уведомления: системный тост, звук, каналы push |
| `dsh-mcp-manager` | панель MCP-серверов (локальная редакция 0.2.12) |
| `modsearch` | веб-поиск для агента |
| `dsh-better-sidebar` | боковая панель с браузером и вкладками |
| `skill-explorer` (`dsh-web`) | навыки агента |
| `archify` | схемы Mermaid |
| `dsh-russian-lang` | русский интерфейс |
| `dsh-browser-agent` | 19 инструментов `browser_*` поверх встроенного браузера |

### MCP-серверы

- `1c-bsl-checks` — проверка кода по правилам 1С. Движок `bsl-analyzer` 0.4.3 лежит в поставке
  (`%USERPROFILE%\.dsh\bsl-analyzer`), включается галочкой в настройках «1С: Анализ кода».
- `v8std` — поиск по документации платформы 1С, БСП / SSL и стандартам, разбор диагностик ACC и BSLLS.
  Публичный сервер, ключ не нужен.
- `1c-platform-context` — справка по объектной модели **установленной** версии платформы:
  типы, методы, свойства, конструкторы, значения системных перечислений, проверка BSL против платформы.
  Локальный `bsl-context-rs`, поднимает плагин `dsh-1c-project-properties` по пути к платформе.
  Инструменты видны агенту как `mcp__1c-platform-context__*`.
- `rlm-tools-bsl` — поиск и навигация по коду 1С, индексы проектов. Живёт в плагине
  `dsh-1c-project-properties`.
- `engram` — память агента, внутри `dsh-engram-memory`.

### Рантаймы и payload

- `uv 0.13.7` — первый запуск ставит движок `rlm-tools-bsl` из индекса.
- `MinGit 2.56.0.4` — `git.exe` без графического интерфейса, Git Bash, Perl и справки.
  Первый запуск распаковывает его в `%USERPROFILE%\.dsh\git`.
- Набор правил [ai_rules_1c](https://github.com/comol/ai_rules_1c) как payload — источник
  предметных правил, лежит офлайн.
- Рантайм `@deepseek-ai/dsh@0.2.2-rc.1` внутри приложения.
